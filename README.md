

# jscommons
library comprising reusable utility code, both for browser and for node server

## Installation
    npm install @jtviegas/jscommons

## Usage
    ```
    const commons = require('@jtviegas/jscommons');

    new commons.ServerError(...)
    commons.getTableNameV1(..,..,..)
    ```
